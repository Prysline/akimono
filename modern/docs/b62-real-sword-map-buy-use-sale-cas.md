# B-62｜真實劍市地圖 #14 → 木刀 #40 來源產出 → `ken-sale` 實際販售／收入

> 2026-11-22。延續 B-61 的原版五種劍需求 `popular/2`，本輪把可驗證的**木刀實際貨源、玩家持有庫存、展示架及自然銷售**接上單店世界，並以原版 Perl `UseItem` 與原版 17 鍵 EVENT 受控時間片核對。此處不是完整原版商品／任務地圖系統，也未支援同時持續多個 EVENT、原版完整 RNG/hash 順序或36小時結算。

## 正確來源：不從空白原版市場硬買木刀

固定 `custom/inc-item-data.cgi` 的木刀 ITEM #40「木刀」價格1,200、`pop 3h`、`limit 600`、`plus -1h`。原版市場初始化後的59項 PLUS 會對 #40 **扣減而不是補充**，空白市場並無木刀可供直接購買。如果把它當成可直接批發的正供給，會產生未經來源支持的假庫存。

原版 ITEM #14「到劍市的地圖」才有 `plus 1h`、售價10,000、`limit 3/3`、`noshowcase`。本輪由真正的來源市場 `GetWholeStore` 批發展示得到其索引與合法報價，經受控 `buy-s.cgi` 數值投影真扣掉市場庫存與玩家金錢、`paytoday`，消耗原版初始交易時間600秒，才在玩家 item[13] 放入一份真的地圖。

該地圖的原版 `@@USE`：基準時間4h／熟練時間2h（固定 `ItemUseTimeRate=0.5`，所以首次使用7200秒）、使用費12,000、獲得 EXP 2%（數值20）、有 `funcb _local_` 先於使用的機率加倍分支、`func lostbook` 之後的地圖損毀機率分支。五個來源 GET 結果分別是每次最多10個：木刀40%、鐵劍35%、鋼鐵劍15%、秘銀劍6%、奧利哈鋼劍3%，最後兩個結果另有原版訊息文字。

本輪只接受**確切已審查的狹窄亂數分支**：第一筆 `rand(1000)` 跳過加倍；接著依真 `MakeAmount` 順序10筆木刀均成功、其餘40筆四種劍均失敗；最後一筆 `lostbook` 不損毀地圖。**合計52筆 rand(1000)**，所有非本輪受審查的結果（雙倍、其它劍產出、地圖損毀、缺／多／錯誤抽樣）直接拒絕整筆操作，不會虛構其他商品。通過後玩家真的新增十把木刀，地圖維持一份，並實際扣除費用、使用時間及增加20點該地圖熟練度。原版 `UseItem`、`MakeAmount`、`UseTime`、`CheckWholeStore`、`lostbook` 與地圖前置回呼的原文驗證見 [原版 Perl 真執行探針](../tests/original-perl/original-b62-sword-map-use-probe.pl) 與 [原版 Perl 斷言](../tests/original-perl/original-b62-sword-map-use.t)。

## 商品需求變化現在會改變玩家真實成交

原版 `inc-turn.cgi` 在 `DataRead` 階段載入持續的 `ken-sale` 後才計算 `ITEM` 的潛在購買人數。木刀基準 `popular=10800` 秒，活動中 `popular=5400` 秒；在同一個30分鐘、單商店、單木刀展示架、標準售價1200的來源時段，與固定原版抽樣相同時：

| 欄位 | 尚未啟動（基準） | `ken-sale` 正在活動 |
| --- | ---: | ---: |
| 木刀原版 `popular` 秒數 | 10,800 | 5,400 |
| 玩家此次實際成交 | 2 把 | 5 把 |
| 玩家實際營收增加 | 2,400 | 6,000 |
| 原版定價 | 1,200 | 1,200 |

完整流程使用 **真正的來源市場初始狀態 → 真店鋪 → 原始59項 PLUS → 購地圖#14 → 使用地圖產出#40 → 真上架 → B-56 完整 EVENT 時間片**：第一個30分鐘觸發 `ken-sale`，本片由於 DataRead 時尚未啟動所以成交2把；活動在片尾才保存起始事件期限。B-43 真雙世代磁碟存檔後，由**全新世界 adapter 重新載入**，第二個30分鐘因 DataRead 活動已有效而成交5把，真實扣除木刀、增加收入及 itemtoday[40]，並再次磁碟儲存。另以同一來源世界的「無活動」對照投影確認若 `ken-sale` 未活動，本片只成交2把。**這次不只是潛在買家預測**，而是事件對玩家真實商品數量和金錢的數值影響。
