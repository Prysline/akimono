# 標準街原始介面參考｜B-40 起本機可操作測試 UI

> **目的：** 使用原版畫面資訊架構與操作慣例，製作讓使用者能真正按、看、驗證新版 Core 的繁體中文本機介面。**不是**直接使用舊 CGI／Perl 當成新版 API，也不是複製缺乏轉載授權的原始圖片。這是原版 UI 參考與實作規格；**B-40 已加入可執行的本機 HTTP／繁體中文互動 UI**。實作驗收與開啟方式見 [B-40 操作文件](b40-local-browser-market-buy.md)，原版其它功能仍須後續階段接入。

## 必須分開的內容

- **可參考：** 原版資訊架構、流程、欄位、用語、頁籤概念、資料密度、操作回饋方式；配合可讀性／響應式調整視覺。
- **不直接複製：** 舊版 Cookie 密碼方案、CGI query string 中的憑證、無完整審核的 HTML／JS 程式片段、絕對路徑、原版素材圖片／音樂。原始 repo README 明確指出圖片與音樂不能直接再次散布。
- **交付必須可操作：** 真本機 HTTP 啟動命令、可在瀏覽器點擊並向既有 `Game Core / Street Module / WorldState` 提交合法命令；失敗要見到明確原因，成功後用**提交完成的世界快照**重新渲染，不在前端假改錢、庫存、時間。
- **驗收可重現：** B-40 至少能「空白世界→開店→查看市場→無貨拒絕→來源合法供貨→真購買 #10→倉庫確認庫存＋扣款」；若尚有原版前置條件未滿足，誠實顯示待完成，不把人工供貨算成玩家流程。提供具體網址、操作步驟、預期資料前後對照及瀏覽器 UI 測試。

## 後續增量方式

B-40 完成最薄「店內／市場／倉庫」頁面及進貨操作；後續在**相同頁面**補展示架設定與販售、時間與結算、存讀檔。待真正閉環可用後再整理正式繁體中文視覺，並擴充其它街道。避免先建立華麗但所有按鈕都只有假回應的原型，也不要等完整後端出來才給人可按的畫面。

## B-40 實作附註（2026-11-21）

實際程式為 [本機 HTML](../local-ui/index.html)、[互動前端 JS](../local-ui/app.js)、[CSS](../local-ui/style.css)、[Node HTTP 入口](../scripts/dev-local.mjs)。在 `modern` 內執行 `npm run dev:local`，於 `http://127.0.0.1:4173` 操作「初始化來源世界 → 開店 → 無貨拒絕 → 來源 PLUS 供貨子步驟 → 商品 #10 真購買 → 倉庫核對」。店內／市場／倉庫共享同一 GameCore／StreetModule／WorldState，並顯示每筆來源收據、revision、資金與商品庫存。

市場空貨時**仍允許按購買**，以便實際測試 Core 拒絕；未完成的上架／販售／週期結算／存檔一律停用。現版不使用原版圖片、CGI 密碼／Cookie 或未驗證的其它商品交易。來源供貨目前只執行受控 B-37 片段，並非真時間流逝或原版完整 `inc-turn.cgi`。


## B-40 UI 視覺修正：Standard Skin 優先（2026-11-21）

使用者實際在 Windows 本機開啟 B-40 後指出：現代綠色卡片式 dashboard 與原版印象相差過大。由此將 B-40 先前的「大型綠色頁籤、1080px 儀表卡片」替換為**原版 Standard Skin 視覺與資訊層級**，只改 `modern/local-ui/index.html`、`style.css`、`app.js` 與 HTTP E2E 對 UI 的檢查，不改原版來源、API、GameCore、WorldState、商品或價格。

- 上方主選單照原始 `custom/inc-menu.cgi` 取五組「自店／取引／情報／施設／交流」；自店次選單「店內／倉庫／掃除／收支／手續」，交易次選單「市場／商店街／委託所／宮殿」。只有店內、倉庫、市場已接到真資料與 API；其餘次選單維持禁用，其餘主分類可切換至清楚的「尚未實作」頁，不模擬未驗證玩法。
- 使用固定 `sindex.html`、`smain.html` 的基本淡色方向：白底 `#FFFFFF`、淡紫白表格列 `#FCFBFF`、淺綠標題 `#D9FF99`、淺黃選中提示 `#FFF789`、灰字及灰紫連結。文字標題替代原始 Logo；不搬運可能有著作權疑義的 `bg.gif`、`mark.png`、`logo.gif`。
- 主要狀態以緊湊表格顯示店舖、資金、人氣、可用行動時間，不再四張現代 dashboard 卡。營業與市場／倉庫維持原版文字、表格、簡單輸入及操作回饋。
- 技術性世界 ID、revision、固定世界時間、市場來源與 JSON 收據收入可展開的測試資訊，主畫面仍清楚提示「記憶體世界、無存檔」。初次設定的建立世界／開店表單於開店後自動收起，但可再展開。
- 保留原本 `/api/initialize`、`/api/open-shop`、`/api/supply`、`/api/buy` 的資料流、source-backed 失敗與成功回報；市場供貨折進獨立開發測試區，以避免誤認是真實時間推進。手機窄版只調小排版與換行，不虛構新玩法。

**驗收方式：** 更新 `test/task02-baseline-on-s1` 後，`cd modern && npm run dev:local`，開啟 `http://127.0.0.1:4173`。先在自店＞店內「營業準備」初始化／開店，點上方「取引」再點「市場」，可在展開的「原版市場供貨子步驟」供貨並真買 #10；回「自店＞倉庫」查看實際庫存。測試自店／取引／情報／施設／交流的選單切換、禁用功能、來源收據，以及窄視窗表格。HTTP E2E 另檢查原版 5 組選單、三個真功能、經典色彩與市場 #10 交易仍正常。

此修正是**原版來源可驗證的布局／配色重排**，尚未由使用者本人在 Windows 視覺驗收，不表示已達到任一歷史伺服器特殊皮膚的逐像素外觀。後續 B-41 直接在這個原版風格介面接續真上架／自然販售，不自動重新啟用 dashboard 設計。


## B-40 第二輪實際 UI 回饋：壓縮導覽間距／「交易」本地化／首頁界線

使用者指出導航與表格距離太寬，且原版日文主選單 `取引` 應譯為繁體中文「交易」。此次僅調整現有繁體中文測試 UI，不變更固定原版 `custom/inc-menu.cgi` 的日文來源文字：

- `modern/local-ui/index.html`：主選單顯示「【交易】」，並將真店鋪狀態表格移到 `</header>` 後、所有測試提示／建店表單之前；第一張表格直接銜接上方導覽，頁面資訊仍由原版世界資料填入。
- `modern/local-ui/app.js`：`groupNames.trade='交易'`，導覽階層與點擊切換狀態一致；市場仍沿用 `data-group='trade'` 的程式識別，不改 API 或其他字串。
- `modern/local-ui/style.css`：將主標題、導航次選單、麵包屑、提示、區塊與狀態表格的上下空間收緊；既有 RWD、操作控制、原版配色維持。
- HTTP E2E：確認五組主選單含「交易」且沒有未翻譯的「【取引】」；確保狀態表格位於 header 與提示之間、CSS 間距和原市場買入 API 回歸可通過。

**關於是否現在重建原版 `sindex.html` 首頁：目前維持 B-40 進入後可直接建立世界與開店的測試模式，不另外製作看似可登入卻沒有真認證的首頁。** 原版 `sindex.html` 具名稱／密碼／Cookie／進入商店等真正帳號流，與現階段記憶體單機入口不同；現在先以已核對原版色彩和選單的內頁進行手動經營測試。待完整可玩循環與真正讀寫／帳號入口的需求確定時，再單獨建立原版風格首頁，避免假登入、來源未授權圖片及錯置里程碑。

這是外觀／前端驗收的小範圍修改，不代表 B-41 上架、自然販售、結算、存檔或認證已完成。最終雙 CI 與 GitHub HEAD 必須同 SHA。

## B-41 增量：保留原版 Standard Skin 的倉庫架位／店內快轉（2026-11-21）

保留 B-40 由使用者實際回饋修正的「【交易】」、狹窄主導覽與店舖表格間距，不恢復現代綠色 dashboard。原版固定 `stock.cgi`／`sc-s.cgi` 的「倉庫 → 第 1 架」在現有倉庫表格下新增真正可按的展示架設定，只列出本次來源確認的 #10（原價5,000 G）與「清空展示架」。`edit-showcase` 必須由現有 GameCore／Street Module 審核真庫存、架位、原版行動時間；尚未購得時按上架會真拒絕，前端不插入測試庫存。

「自店 > 店內」在原版展示架與當日進貨／售額表格下新增**時間快轉測試區**：1分鐘、10分鐘、30分鐘、1小時快捷及自填1～60分鐘。這些按鈕送 `POST /api/advance-time` 以原版隨機來源流、同一遊戲世界時間及商品演算；「1／10／30／60 分鐘」是方便測試的預設間隔，不聲稱原版菜單一定這樣排。運行結果在店內／市場／倉庫共用快照同步呈現，並有完整收據。跨來源未實作36小時結算線明示拒絕；獨立 B-37 供貨按鈕照舊不使世界時間流逝。

對照原版自然販售僅已確認 #10、單店、5000 G 售價與可控 1～60 分鐘來源片段；完整每期成本／回呼／排名排序、存讀檔與所有其他商品仍在下一階段。開啟方式、原版 Perl／Node／HTTP E2E 索引見 [B-41 逐步驗收](b41-real-market-showcase-natural-sale.md)。

## 2026-11-24｜商品明細展示架緊湊化與原版直接售價（獨立 UI 工作分支）

- 使用者確認：**架號與現有架上商品＋售價**保留為窄幅下拉選單；商品沿用當前明細，不再顯示第二個「商品」選擇器。移除先前 JS 殘留不存在的 `shelfSelect`／`newlyOpened` 參照。
- 同一行依序顯示「架號」「標準價格的［比例選單］［僅選自訂比例才顯示的比例輸入框］或［整數售價］G［陳列］」，`flex-wrap` 在容器不足時才換行。原版快捷比例 `50,60,70,80,90,100,110,120`，`100` 顯示「相等」；自訂比例限制整數 `1–200`。選比例即用原版 `int(basePrice * per / 100)` 更新售價；手動售價優先、不反向改比例。
