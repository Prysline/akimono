## R4 整合介面與實作限制

現在 `use-item` 對未知 `world.events`、非空／未知 `period.eventState` 仍 fail-closed；不應將它們設為空物件來放行。未來如 source USE 需要 `needevent`，應由 R4 審閱的 EVENT 投影提供可核對、可重播的事件生效資訊，包含事件鍵與生效時序，R2 只做來源判斷。跨越 36 小時的時間推進與 SortDT 仍由 R4 統一處理。

無回呼、無 EVENT 的正常製作優先以同一 `use-item` Registry 載入，不另設每件商品專用 command。接入前仍必須先對該組合法材料／GET 機率／原版職業縮時與 overflow／CheckWholeStore 以凍結 Perl 做直接差分，並通過 HTTP、CAS、雙世代存檔和重啟的玩家流程。未通過時狀態維持未接入。
